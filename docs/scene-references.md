- **日期：** 2026-11-16
- **目的：** 为导演台 47 个待建/已建简化场景提供建模前可核对的公开参考图——核对颜色、比例、家具形态与布局。每条参考只给链接，不随包附带图片文件。第 1–12 节为上一批 12 个研究场景；第 13–36 节为本批 24 个高频日常场景（学校 7 / 家庭 3 / 公司 5 / 联想补充 9）；第 37–47 节为成对繁荣/衰败场景（11 对，唐长安/宋汴京/圆明园/大明宫/罗马/庞贝/楼兰/商场/豪宅/学校/村庄）。第 48–73 节为本批 26 个室外片场（自然 12 / 植物园艺 3 / 动物相关 2 / 城市户外 4 / 古代户外 5）。

### 时代锁（不得出现）
- 不要做成美式单人豪华病房（单床 + 沙发 + 独立卫浴套间）；不要出现只有一张床的“VIP 病房”作为标准间。

## 4. set-qinhan — 秦汉

**证据状态：据汉代反推。** 秦代室内直接证据几乎为零，本节全部证据都是汉代的：马王堆漆器（西汉）、打虎亭汉墓壁画（东汉晚期）、秦始皇陵封土（秦代地面遗存）。**一张汉代壁画只能证明汉代，不能直接当作秦代证据；阿房宫未建成、未被烧毁，只剩夯土台基——绝不能做成一座完工的宫殿。**

- 阿房宫不得呈现为完工的宫殿（只剩夯土台基）。
- 席位 = 等级：分餐、按身份排座，不得画成围桌合餐。

## 6. set-yuan — 元

**证据状态：复原（薄证据）。** 元代实物证据最少。本节三条参考各有不同的证据等级，已分别标注：永乐宫是元代道观实物（直接证据，但为宗教建筑）；大卫花瓶是元代青花瓷实物（直接证据，但为高端瓷器）；蒙古包照片是现代蒙古包（最接近的现存形态，标注为“现存类比”，不是元代实物）。

- 不得出现明式素面黄花梨家具（那是明代的）；蒙古包里不得出现雕花大床、博古架（圆帐摆不下，也不符合游牧陈设）。
- 蒙古包家具 8 件套中不含床；佛龛与十字架可以共存（多元信仰），不要画成单一宗教空间。
- 汉式宫殿要更大、更彩、多色琉璃瓦；家具“大/厚/重”、以漆器为主。
