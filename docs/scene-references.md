# ZhuyaHome 导演台 · 12 个新场景参考图包 (Scene Reference Pack)

- **日期：** 2026-11-16
- **目的：** 为导演台 12 个待建简化场景提供建模前可核对的公开参考图——核对颜色、比例、家具形态与布局。每条参考只给链接，不随包附带图片文件。
- **使用规则：** 图片均为链接引用，不入库。只有明确标注为公有领域 (Public domain) 或 CC0 的文件才可下载进仓库；其余 CC BY / CC BY-SA 文件仅作参考，入库使用须按许可证署名并遵守相同方式共享条款。
- **核查方法：** 2026-11-16 对文中每一个 URL 执行 `curl -I`，全部返回 HTTP 200（唯一例外见文末“未通过核查的 URL”：一个连字符变体返回 404，已弃用，未收入正文）。许可证只写实际看到的来源；凡未在文件页上确认的，一律写“未核实——使用前请先打开文件页确认”，不编造许可证。
- **诚实说明：** 部分 Commons 文件页在本次核查中被抓取方以 403 拒绝（疑似限流），这些文件的“文件页 URL”未收入正文，改用 Wikipedia 文章内嵌的缩略图 URL（同样 `curl -I` 验证为 200）或直接删去，详见文末。

## 3. set-hospital — 医院病房

**证据状态：** 直接证据（多床病房形态），但均为历史照片。**现代中国病房实拍 + 陪护物品（折叠陪护椅、脸盆、保温壶、饭盒）没有找到可自由使用的公开照片——本节存在缺口，见下。**

### 参考图

**3-1. 印度德里 Lady Hardinge 医学院附属医院病房，1921 年**

**3-2. 克里米亚战争时期斯库塔里医院病房，1856 年石版画**

### 缺口
- **现代中国病房、床头设备带 + 呼叫按钮、夜间展开的陪护折叠椅、床头脸盆/保温壶/饭盒：均未找到可自由使用的公开照片。** 检索到的现代病房图多为新闻图片或社交媒体照片，版权不明，未收入。这些元素请按文字描述建模，并在之后补拍/补找授权图。
- 本节两张图都是历史照片，不能直接当作现代病房的色彩与设备参考。

### 时代锁（不得出现）
- 不要做成美式单人豪华病房（单床 + 沙发 + 独立卫浴套间）；不要出现只有一张床的“VIP 病房”作为标准间。

## 4. set-qinhan — 秦汉

**证据状态：据汉代反推。** 秦代室内直接证据几乎为零，本节全部证据都是汉代的：马王堆漆器（西汉）、打虎亭汉墓壁画（东汉晚期）、秦始皇陵封土（秦代地面遗存）。**一张汉代壁画只能证明汉代，不能直接当作秦代证据；阿房宫未建成、未被烧毁，只剩夯土台基——绝不能做成一座完工的宫殿。**

### 时代锁（不得出现）
- 无椅子、凳子、高桌；坐具只用席 + 低榻（榻足 17–19cm）+ 几 + 案（12–14cm 高）。
- 无玻璃窗、无青花瓷、无紫砂、无辣椒/土豆/玉米。
- 阿房宫不得呈现为完工的宫殿（只剩夯土台基）。
- 席位 = 等级：分餐、按身份排座，不得画成围桌合餐。

## 6. set-yuan — 元

**证据状态：复原（薄证据）。** 元代实物证据最少。本节三条参考各有不同的证据等级，已分别标注：永乐宫是元代道观实物（直接证据，但为宗教建筑）；大卫花瓶是元代青花瓷实物（直接证据，但为高端瓷器）；蒙古包照片是现代蒙古包（最接近的现存形态，标注为“现存类比”，不是元代实物）。

### 参考图

**6-1. 永乐宫（山西芮城），2026 年实拍**

### 时代锁（不得出现）
- 不得出现明式素面黄花梨家具（那是明代的）；蒙古包里不得出现雕花大床、博古架（圆帐摆不下，也不符合游牧陈设）。
- 蒙古包家具 8 件套中不含床；佛龛与十字架可以共存（多元信仰），不要画成单一宗教空间。
- 汉式宫殿要更大、更彩、多色琉璃瓦；家具“大/厚/重”、以漆器为主。
