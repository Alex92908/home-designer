# 拍摄/录屏清单（录一次，多平台复用）

> 设置：竖屏 9:16、1080p 以上、**鼠标光标可见**、点击**放慢且果断**（别乱晃）、关掉/打码任何个人信息（账号名、邮箱、价格隐私）。每个片段**多录 2–3 遍**取最顺的。

## A. 核心屏录片段（必录）
- [ ] **打字输入**：在输入框敲「现代三层别墅 带泳池和院子」→ 回车（录完整打字过程，有节奏感）
- [ ] **生成时刻**：3D 户型/房子从无到有「长出来」的那几秒（**最关键的爽点帧**，多录几遍）
- [ ] **房间编辑**：拖动家具、切换房间（体现「随便改」）
- [ ] **换材质**：换地板/墙面/风格，画面明显变化
- [ ] **实时报价**：换东西时右侧报价数字跳动的特写
- [ ] **第一人称漫游**：进客厅 → 推到落地窗 → 走出去到院子/泳池（一镜到底最好）
- [ ] **外观/立面**：切「整体外观」，绕着别墅转一圈（白墙木饰面、泳池别墅最出片）
- [ ] **院子**：俯视院子布局（门廊/泳池/户外厨房/木格栅）
- [ ] **AI 出效果图**：点一键出图 → 出图过程 → **下载**（露出右下角水印 `zhuyahome.com`）
- [ ] **一键分享**：点分享、复制链接（体现「发给家人/施工」）
