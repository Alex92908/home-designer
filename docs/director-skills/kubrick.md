# 斯坦利·库布里克 — 导演手册（Stanley Kubrick Playbook）

> 范围：斯坦利·库布里克共导演 13 部长片（1953–1999），本手册以 5 部锚定片为核心：科幻《2001 太空漫游》*2001: A Space Odyssey* (1968)、《发条橙》*A Clockwork Orange* (1971)，恐怖《闪灵》*The Shining* (1980)，战争《全金属外壳》*Full Metal Jacket* (1987)，《大开眼戒》*Eyes Wide Shut* (1999)。
> 主类型：**科幻**。另注：恐怖（《闪灵》）、战争（《全金属外壳》）、反乌托邦犯罪（《发条橙》）、情欲悬疑（《大开眼戒》）——库布里克每换一种类型就重造一次语言，但底层 DNA 不变。
> 核心 DNA：**对称的一点透视 + 冷静的凝视 + 制度吞噬个人** —— 画面极度工整、运动极慢、音乐极讲究，暴力来得突然、短促、仪式化；从不解释谜，只把谜摆在画面正中央让你自己看。
> 状态：已接入导演台风格预设（2026-11-16，`src/lib/directorStyles.ts`）。

## 什么时候用

- 科幻短剧、太空/飞船、人工智能、封闭空间里的人慢慢失控。
- 想让一场戏“看起来很贵、很冷、很有秩序”时用这套：一个对称房间 + 一次极慢推近就够。
- 恐怖或战争短剧也可用 —— 《闪灵》的走廊和《全金属外壳》的军营是同一套语言换了布景。
- 预算低但要出质感时优先用这套 —— 库布里克的核心是构图、节奏和克制，不是群众演员。

## 1. 布景 SETS — 6 种场景类型

|---|---|---|---|---|
| 1.1 | 飞船 / 空间站内部 —— 白色无菌舱 | 《2001 太空漫游》(1968)：发现号（Discovery One）的离心机舱、白色走廊、红色 HAL 9000 之眼；宇航员在旋转舱里慢跑、吃饭、睡觉，一切日常都被拍得像仪式 | 布景即系统 —— 白色、干净、对称，人在里面显得渺小、可替换；红色是全片唯一的警告色，只留给 HAL 的镜头之眼 | 场景：室内飞船舱（用现代室内/办公室布景改 dress，白墙 + 对称走廊）；灯光 cold；走位：沿中轴线直线行走，绝不斜穿 |
| 1.2 | 荒原与黑石 —— 人类起点 | 《2001 太空漫游》(1968)：开场“黎明的人类”—— 荒漠、猿人、竖立的黑色方碑；猿人拾起骨头当武器，抛向空中，跳切成轨道上的卫星 | 一个物体即全部剧情 —— 黑石不解释、不动、不说话，只竖在那里；前后两场戏之间隔着几百万年，靠一个剪辑完成 | 场景：沙漠 / 山地户外；机位 crane-up 拉高，让人和黑石都变小；注：导演台没有剪辑/转场特效，骨头→卫星只能做成两条分镜先后排列（见 2.5） |

| 1.4 | 军营 / 战场废墟 —— 制度的车间 | 《全金属外壳》(1987)：前半在帕里斯岛（Parris Island）新兵训练营 —— 宿舍、操场、厕所，哈特曼教官吼叫着把人“拆掉重造”；后半在顺化废墟，狙击手藏在楼里 | 布景分两半、调子分两半 —— 前半是封闭、重复、被吼叫填满的室内，后半是开阔、破碎、看不见敌人的室外；制度先造人，再把人送去送死 | 场景：室内宿舍/训练场 + 户外废墟街道（用现代街道/户外布景）；灯光 day（操场）/ overcast（废墟）；动作：stand、turn、march 式 walk 排成直线 |
| 1.5 | 未来都市 / 奶吧 —— 光鲜的反乌托邦 | 《发条橙》(1971)：科罗瓦奶吧（Korova Milk Bar）—— 白色人体家具、未来主义室内；亚历克斯一伙穿白衣、戴圆顶礼帽，深夜在街头施暴；后半是监狱与路德维科疗法（Ludovico）的白色治疗室 | 未来不是高科技，是品味 —— 白色、光滑、刻意时髦的室内，装着最原始的暴力；治疗室比街头更冷、更白，暴力被“科学”重新包装 | 场景：室内酒吧/餐厅（用现代餐厅/咖啡馆布景）+ 室内白色治疗室；灯光 cold / neon；服装：白衣 + 圆顶礼帽（见 5.1） |
| 1.6 | 封闭豪宅 / 深夜公寓 —— 面具舞会 | 《大开眼戒》(1999)：纽约圣诞夜 —— 公寓里挂满圣诞灯，豪宅里的面具舞会，人物戴面具、穿斗篷，在仪式感极强的长镜头里慢慢走 | 欲望被拍成仪式 —— 不拍激情，拍排队、等待、被注视；圣诞灯是暖的，人是冷的 | 场景：室内豪宅/大厅 + 室内公寓；灯光 candlelight（舞会）/ warm（公寓）；走位：缓慢 walk，配 indoor-medium，不抢拍 |

## 2. 拍摄 FILMING — 5 种模式

| # | 模式 | 例子 | 关键点 | 导演台可用的设置 |
|---|---|---|---|---|
| 2.1 | 一点透视 + 完美对称定场 | 《闪灵》(1980)：丹尼骑三轮车，走廊所有线条汇向画面正中的消失点；《2001 太空漫游》(1968)：空间站走廊、飞船对接，同样居中对称 | 先让观众感到“秩序”，再让秩序变得可怕 —— 对称不是装饰，是主题：系统要求人服从几何，人一偏离就出事 | 机位：indoor-wide 居中定场，人物放在消失点上；走位沿中轴线 |
| 2.2 | 极慢推近 / 滑行，长时间不切 | 《2001 太空漫游》(1968)：飞船对接着《蓝色多瑙河》慢慢靠近；《闪灵》(1980)：Steadicam 在丹尼身后低低滑行，轮子碾过地毯又碾过木地板，声音是唯一的节奏 | 慢不是拖，是凝视 —— 镜头不动声色地逼近，观众自己开始害怕；切得越少，紧张越真 | 机位：dolly-in（户外）/ indoor-medium 缓慢推近；用走位时间拉长来模拟“慢”（注：导演台没有真正的慢动作/速度控制，慢只能靠长走位时间 + 长 hold，不能调播放速度） |
| 2.3 | 音乐先行，画面反衬 | 《2001 太空漫游》(1968)：飞船对接配施特劳斯《蓝色多瑙河》，星门之旅配利盖蒂；《发条橙》(1971)：暴力场面配贝多芬第九交响曲；《闪灵》(1980)：大段沉默，只有脚步和轮子声 | 音乐不烘托情绪，音乐和画面互相顶撞 —— 优雅的音乐 + 冰冷的画面 = 不安；沉默本身就是一种配乐 | 音乐库：选古典/庄严曲目配太空或仪式场面；SFX：只留脚步、轮子、呼吸声，关掉多余音效 |
| 2.4 | 冷眼旁观，绝不解释 | 《2001 太空漫游》(1968)：HAL 被鲍曼一颗颗拔掉记忆，边唱《黛西·贝尔》边慢慢“死去”，镜头不煽情、不加速；《闪灵》(1980)：结尾那张 1921 年的舞会照片，没有一句台词解释杰克为什么在里面 | 观众必须自己拼出意义 —— 不给闪回、不给独白、不给“原来如此”；谜留在画面里 | 拍摄模拟：preview 只检查构图和走位是否居中对称；剧本：rule-based parser 只写动作和走位，不写解释性台词 |
| 2.5 | 一个跳切压缩全部时间 | 《2001 太空漫游》(1968)：骨头抛向空中，下一镜就是轨道上的卫星 —— 几百万年压缩成一次剪辑；《闪灵》(1980)：丹尼在走廊遇见双胞胎，静止两秒，下一镜已是血 | 跳切是库布里克最便宜的特效 —— 两个画面形状、方向、大小越像，切得越狠，时间跨度越大 | 分镜：把前后两镜并排写进 storyboard.json，形状/方向对齐；注：导演台没有剪辑/转场特效，做不出真正的 match cut，只能靠两条分镜的构图呼应 |

## 3. 动作 ACTION — 5 条原则

| # | 原则 | 例子 | 导演台可用的设置 |
|---|---|---|---|
| 3.1 | 日常仪式先立住，再让它失控 | 《2001 太空漫游》(1968)：宇航员在离心机里慢跑、吃饭、刮胡子 —— 日常越正常，HAL 出错越可怕；《闪灵》(1980)：丹尼每天骑三轮车同一条路线，直到在走廊尽头撞见双胞胎 | 先拍三遍“正常”，第四遍才出事；失控的不是动作，是节奏断了 | 动作预设：walk / run（离心机慢跑）/ sit / stand 循环三遍，第四遍换成 hide 或 fall |
| 3.2 | 暴力突然、短促、仪式化 | 《发条橙》(1971)：亚历克斯一伙的“超暴力”来得快、拍得冷，没有追逐和叫喊；《全金属外壳》(1987)：厕所里的一夜，派尔（Pyle）先崩溃再开枪，全程安静得可怕；《闪灵》(1980)：杰克举斧劈门（"Here's Johnny!"），一下一下，有节奏 | 暴力不是高潮，是仪式 —— 动作要短、要重复、要冷；喊叫和快切会毁掉它 | 打斗编排：3–8 beats，只用 punch / kick / block / dodge / fall / getUp，每 beat 之间留 hold；注：导演台没有枪械/射击动作，枪战只能用 fight + SFX（枪声）暗示，绝不在画面里演开枪 |
| 3.3 | 制度化训练 / 驯化是动作本身 | 《全金属外壳》(1987)：哈特曼教官吼叫、罚站、齐步走，把新兵“拆掉重造”；《发条橙》(1971)：路德维科疗法 —— 亚历克斯被绑在椅子上、撑开眼皮，被迫看暴力影像，配贝多芬 | 训练场面不用打斗 —— 齐步、立正、转身、重复口令，本身就是暴力；被驯化的人越不动，越可怕 | 动作：stand / turn / walk 直线队列 + point（教官）；被驯化者只用 sit / idle，全程不动 |
| 3.4 | 重复 + 迷路 | 《闪灵》(1980)：丹尼骑三轮车反复经过同一条走廊，杰克在树篱迷宫里越走越深；《2001 太空漫游》(1968)：鲍曼在星门后的白色房间里一次次遇见“自己”—— 年轻的自己、年老的自己 | 同一个走位走三遍，第三遍换一个细节（多一扇门、少一个人），观众就开始怀疑空间本身 | 走位：同一条 waypoints 路线重复，配 height 不变、time 拉长；迷宫用户外布景 + crouch / hide |
| 3.5 | 凝视 / 对峙代替追逐 | 《2001 太空漫游》(1968)：HAL 的红色镜头之眼盯着宇航员，鲍曼盯着它，一句话不说；《闪灵》(1980)：杰克盯着镜子、盯着打字机、盯着妻子，全片最可怕的镜头是他的脸 | 追逐是热的，凝视是冷的 —— 库布里克要冷的；让两个人互相站着看，比跑起来更吓人 | 动作：stand / idle 对峙 + indoor-closeup 给脸；HAL 之眼用灯光 dramatic + 一个红色道具光点暗示（无真实 HAL 模型） |

## 4. 镜头 CAMERA — 4 种模式

| # | 模式 | 例子 | 导演台可用的设置 |
|---|---|---|---|
| 4.1 | 宽景、对称、深焦 —— 默认机位 | 《闪灵》(1980)：走廊、舞厅、迷宫俯瞰，全部居中对称；《2001 太空漫游》(1968)：空间站、飞船内部，人物在画面里很小，建筑很大 | 肢体和空间同时可见 —— 观众要同时看到人、他站的位置、他离出口多远；绝不在动作中切特写 | 机位：indoor-wide（室内）/ orbit（户外定场）；灯光 cold |
| 4.2 | 极慢推近 —— 只给揭示时刻 | 《2001 太空漫游》(1968)：镜头慢慢推向黑石、推向 HAL 的红眼；《大开眼戒》(1999)：镜头慢慢推向戴面具的人群 | 推近是“逼近真相” —— 一场戏只推一次，推到最关键的那个物体或那张脸上就停住 | 机位：dolly-in，配长走位时间；注：无速度控制，慢靠时间拉长实现 |
| 4.3 | 特写给脸和眼，不给动作 | 《闪灵》(1980)：杰克的脸、丹尼的脸、双胞胎的脸 —— 特写是“这个人正在变”；《发条橙》(1971)：路德维科疗法里被撑开的眼睛 | 特写是心理 X 光 —— 只在人物内心翻转的那一秒用，平时绝不用 | 机位：indoor-closeup；一场戏最多一个特写 |
| 4.4 | 高空 / 大远景显渺小，再落回地面 | 《2001 太空漫游》(1968)：地球、飞船、星门，人在宇宙里只是一个点；《闪灵》(1980)：雪地迷宫俯瞰，杰克在里面像一只困兽 | 尺度就是主题 —— 人越小，系统越大；远景之后必须立刻切回地面的人，让观众感到落差 | 机位：crane-up（户外）拉高，再接 indoor-wide / indoor-medium 回到人物 |

## 5. 装束 COSTUMES — 4 个造型

| # | 造型 | 例子 | 导演台可用的设置 |
|---|---|---|---|
| 5.1 | 白衣 + 制服化 —— 未来与暴力同一套衣服 | 《发条橙》(1971)：亚历克斯一伙白衣、白裤、圆顶礼帽、假睫毛，干净得像制服，干的事最脏；《2001 太空漫游》(1968)：白色宇航服、空姐制服，一尘不染 | 白色不是纯洁，是“系统” —— 所有人都穿同一种白，谁偏离（血、泥、皱）谁就是失控 | 服装预设：白色制服 / 宇航服 archetype，全员同色；失控者只加一处污渍/血迹（换装即弧光） |
| 5.2 | 军装做旧 —— 制度穿在身上 | 《全金属外壳》(1987)：新兵从便装换成军装、剃头、背枪，衣服越旧，人越像机器；顺化废墟里的士兵满身泥，军装和废墟同色 | 换装即驯化 —— 衣服从“自己的”变成“发下来的”，人物就完成了转变 | 服装预设：军装 archetype，做旧、配钢盔；训练前后换装一次 |
| 5.3 | 正装 / 面具 —— 体面的恐怖 | 《大开眼戒》(1999)：面具舞会斗篷 + 面具，正装之下是仪式；《闪灵》(1980)：杰克的格子衬衫、舞会照片里的燕尾服，体面和疯狂同一张脸 | 体面是最好的伪装 —— 越正式，越可疑；面具不是藏身份，是亮身份 | 服装预设：正装 / 礼服 archetype + 面具道具（程序化道具）；注：面具如无对应道具，用服装 + 灯光 candlelight 暗示 |
| 5.4 | 日常衣服变恐怖 —— 不换装，只换状态 | 《闪灵》(1980)：温蒂的毛衣、丹尼的红毛衣，全片没换过，越穿越脏、越穿越破；《发条橙》(1971)：亚历克斯出狱后同一件衣服，人已经不是那个人 | 不换装也是一种换装 —— 同一件衣服穿旧、穿破、穿出血，就是人物弧光 | 服装预设：日常便装 archetype，全程同一套；用灯光 cold → dramatic 表现状态变化，不靠换衣服 |

## 6. 不要抄这些 — 5 个失败模式

1. **对称没有意义就成了壁纸。**库布里克的对称是“系统在看你”，不是好看。模仿者把每个镜头都摆对称、摆居中，人物却没有被系统压迫的感觉，结果只是构图练习。规则：对称镜头必须配一个“系统”—— 飞船、酒店、军营、疗法，缺了它就别对称。
2. **慢成了拖。**《2001 太空漫游》(1968) 的慢，是因为每个慢镜头都在揭示新信息（飞船结构、HAL 的眼神、星门）。模仿者把慢当风格，镜头推半天什么都没发生，观众只会走神。规则：每个长镜头必须回答一个问题（这是什么地方？谁在看谁？下一步会出什么事？），答不出就切。
3. **抄暴力，不抄冷。**《发条橙》(1971) 和《全金属外壳》(1987) 的暴力之所以吓人，是因为拍得冷、短、有仪式感。模仿者把暴力拍热、拍长、拍爽（慢动作 + 特写 + 配乐高潮），就抄成了动作片。规则：暴力场面禁用煽情配乐和特写，只用 fight beats + hold + 沉默。
4. **把谜解释了。**黑石是什么、HAL 为什么发疯、杰克为什么在 1921 年的照片里 —— 库布里克一个都不解释。模仿者忍不住加一句台词、一个闪回、一个字幕“原来如此”，谜一破，整部戏就塌了。规则：剧本里不写解释性台词；观众问“为什么”，答案是“画面里已经有了”。
5. **冷得没有人。**库布里克常被说“冷”，但他的冷里面有人：鲍曼拔掉 HAL 时 HAL 唱歌求饶，温蒂举着棒球棒护着儿子，派尔在厕所里哭。模仿者只抄冷（面无表情 + 对称 + 慢），忘了冷里面要有一句真心话。规则：每场戏至少一个“人”的瞬间 —— 一句求饶、一次护子、一次崩溃，特写只给那一秒。

## 7. 预算 — 便宜 / 贵

**便宜（不用花钱 —— 这就是库布里克的核心）：**
- 对称 + 一点透视：一个房间、一条走廊、居中构图。成本：布景，不用群众演员。
- 慢推近 + 长 hold：dolly-in + 长走位时间。成本：排练时间，不是设备。
- 沉默 + 古典乐：音乐库里的古典曲目 + 脚步 SFX。成本：选曲，不是作曲。
- 一件白衣服 + 一个红点：白色制服 archetype + dramatic 灯光。成本：服装，不是搭建。
- 一个物体即剧情：黑石、红眼、面具 —— 一个道具撑起一场戏。成本：一个程序化道具。

**贵（需要大布景或特效 —— 在导演台里标出来）：**
- 旋转离心机 / 真实飞船内景：《2001 太空漫游》(1968) 的离心机是实打实造出来的旋转布景，导演台里没有旋转布景模型。导演台提示：“旋转舱 —— 用室内布景 + walk/run 走位模拟，别建旋转装置。”
- 星门 / 幻彩特效：《2001 太空漫游》(1968) 的星门是 slit-scan 光学特效，导演台没有 CGI/水/光效模型。导演台提示：“星门 —— 用 neon 灯光 + dolly-in + 音乐库的迷幻曲目暗示，别做 CGI。”
- 大场面 / 雪地迷宫：《闪灵》(1980) 的迷宫和雪景需要大户外布景。导演台提示：“迷宫 —— 用户外布景 + hide / crouch 走位，别建真迷宫；雪地用 cold 灯光 + 白色服装暗示。”
- 年代 / 未来布景：《发条橙》(1971) 的未来主义室内、《大开眼戒》(1999) 的豪宅舞会。导演台提示：“年代布景 —— 复用一间 dress 好的房间 + 换装，别建宫殿。”

**给导演台的底线：** 库布里克是构图 + 节奏 + 克制，不是钱。预设默认便宜档（一个对称房间、一次慢推近、一段古典乐、一个红点），把旋转舱/星门 CGI/大迷宫标为升级项，不是必需项。
