# 导演风格手册 — 索引（Director Skills Index）

> 这是 ZhuyaHome 导演台的“导演知识库”：十二套风格手册，教导演台怎么像不同导演那样布景、拍摄、排动作、选镜头、定服装。
> 状态：十二套手册全部已接入导演台成为风格预设（`src/lib/directorStyles.ts`，控制台下拉框按类型分组选）。更多导演（好莱坞其余、日本/韩国/欧洲、恐怖、科幻、奇幻等类型）按批次接入中。
> 背景：这是 云横店愿景（Chu 2026-11-16 定调：完整的虚拟影棚，提供场地、道具、拍摄、所有资源）里“拍摄”这一支柱的知识部分。场地 = 场景库（10 套已上线，12 套研究场景 + 高频学校/家/公司 + ~20–25 套户外在建，合计 60+ 套）；道具 = 587 件家具 + 程序化 3D 资产 + Sketchfab/NVIDIA 采购（在建）；拍摄 = 导演台（机位预设、走位、打斗编排、动态站位、拍摄模拟、文字驱动动作 —— 在建）+ 本目录的十二套风格手册。
> 仍缺（不要声称完整 云横店 已建成）：人物/演员 + 服装的可视化系统（导演台有人名角色，但没有视觉人物/服装系统）、灯光预设、声音/音乐、剧本编写/导入、独立产品（域名/品牌）。

## 导演台应该怎么用这些手册（接成预设的建议）

每套手册都应变成导演台里的一个可选风格预设。选了预设后，导演台自动应用对应的默认值，用户仍可逐项改：

| 预设 | 机位预设 | 景别默认 | 走位/动作 | 服装提示 | 预算提示 |
|---|---|---|---|---|---|
| **通用** | indoor-wide 定场 → indoor-medium 对话 → indoor-closeup 顿悟 | 全景定地理；特写只给决定性时刻 | 节拍清单：铺垫→触发→追逐/打斗→受挫→代价→反应；必有定场地理镜头 + 反应镜头 | 一个强调色；磨损度；换装即弧光 | 默认便宜；大场面标“贵” |
| **周星驰喜剧** | 宽景对称深焦（肢体喜剧默认）；低角度只给胜利一镜；特写给反应/真诚 | 宽景为主；特写只在反应和真诚转折 | 节奏：静止→爆发→反应定格；招式三拍：铺垫→颠覆→payoff；现成武器；隐藏高手逐级揭示 | 帮派 identical 黑西装+斧头；主角旧衣服→一次干净白衫；最强者穿家常拖 | 默认便宜档；威亚/CGI/体育场标“升级项” |
| **诺兰** | 静态全景或慢推近（默认）；IMAX 全景只给尺度镜头；特写只给顿悟 | 全景 hold 住、人物很小；特写只给图腾/照片/爆炸后的脸 | 时间线模板：2–3 条线 + 视觉代码（彩色/黑白）；交叉剪按危机切；说明=学徒做任务时教；动作：一个真实特技+清晰地理 | 一个剪影单品（帽/外套/徽章）；muted 调色板；做旧；服装必有功能 | 免费档是核心；旋转房间/真飞机/IMAX 风景标“英雄布景” |
| **贝式动作** | 低角度 360° 环绕英雄（默认英雄镜头）；黄金时刻背光；FPV 俯冲 | 全景卖尺度；慢推近英雄；快切 burst 只给布景戏 | 开场即布景戏；升级靠武器化环境；渺小对巨大；混乱后静止英雄时刻；围攻结构 | 军装+真装备；利落英雄造型；粗粝承包商；年代服装定位时空 | 小布景+大机位+黄金时刻是便宜版；真爆炸/封城/军事硬件标“贵” |

**通用规则（四套手册都同意，导演台应始终执行）：**
- 先立地理，再制造混乱（Top 100、诺兰、贝都要求；周星驰要求宽景先展示天井）。
- 反应镜头就是动作 —— 每个动作节拍配一个反应镜头。
- 守住 180° 轴线，越轴警告（导演台已有，Top 100 支持保留）。
- 景别按功能命名，不按尺寸命名（“揭示权力”“逼近”“滑行=通行”“静止=被困”）。
- 服装是变化，不是衣柜 —— 每次换装都应是人物弧光或地位变化。
