# 成龙 — 导演手册（Jackie Chan Playbook）

> 范围：主类型 **武侠/功夫**；另注动作喜剧 —— 成龙的特技即笑点，道具即武器，环境即对手。核查片目：《醉拳》*Drunken Master* (1978)、《A计划》*Project A* (1983)、《警察故事》*Police Story* (1985)、《红番区》*Rumble in the Bronx* (1995)、《尖峰时刻》*Rush Hour* (1998)。
> 注意：《醉拳》(1978) 由袁和平导演；《红番区》(1995) 由唐季礼导演；《尖峰时刻》(1998) 由布莱特·拉特纳导演 —— 那里的风格仍是成龙的明星人格与动作设计，他后来把它带进了自己的导演作品。《A计划》(1983) 与《警察故事》(1985) 由成龙本人导演。
> 核心 DNA：**特技即笑点；道具即武器；环境即对手；疼是真的，笑也是真的** —— 英雄不是不会受伤，是受伤了还爬起来继续打；片尾花絮证明一切都是真的。
> 状态：已接入导演台风格预设（2026-11-16，`src/lib/directorStyles.ts`）。

## 什么时候用

- 武侠/功夫、动作喜剧、现代警匪、追逐与大场面。
- 一场戏需要“打得好笑、笑得疼”时用这套：动作即笑点，道具即武器，环境即对手。
- 预算中等但要出效果时优先用这套 —— 成龙动作的核心是布景、道具与排练，不是 CGI。

## 1. 布景 SETS — 6 种场景类型

| # | 场景类型 | 例子 | 关键点 | 导演台可用的设置 |
|---|---|---|---|---|
| 1.1 | 武馆 / 训练场 —— 练功的地方 | 《醉拳》(1978)：黄飞鸿在父亲与乞丐苏（苏化子）手下练醉拳，武馆、木人桩、酒坛都是训练工具 | 训练场即人物弧光 —— 练功的每一件道具，决战时都会再出现 | 场景：寺庙/农场布景；道具：木桩、酒坛（程序化道具）；动作：crouch / fall / getUp |
| 1.2 | 购物中心 —— 玻璃的故事 | 《警察故事》(1985)：结尾商场大战，成龙从高处滑下挂满彩灯的杆子，撞碎玻璃天花板落地；剧组因碎了太多糖玻璃，戏称本片为“玻璃的故事”(Glass Story) | 商场是成龙最好的战场 —— 电梯、扶梯、玻璃、灯杆，每样东西都能打 | 场景：市场/街道布景（控制台无商场中庭，用市场 + 多层走位代替）；走位：带高度的 waypoints；动作：climb / rappel / fall |
| 1.3 | 海港 / 船 —— 海盗的战场 | 《A计划》(1983)：水师与海盗在 19 世纪末香港海港对决，船、码头、钟楼都是战场 | 海港戏要拍出“水边的危险” —— 掉下去就是真的掉下去 | 场景：海滩布景；动作：climb / jump / swim（注：swim 只有姿势，控制台无水体模型）；机位：crane-up |
| 1.4 | 纽约街头 / 超市 —— 异乡的战场 | 《红番区》(1995)：香港警察强到纽约探亲，卷入街头帮派与超市大战；气垫船追逐、超市货架全是武器 | 异乡即喜剧 —— 主角不懂当地规矩，规矩也不懂他；超市货架是最好的武器库 | 场景：户外街道 + 市场布景；道具：货架/日常物品；动作：run / dodge / block |
| 1.5 | 洛杉矶警局 / 街头 —— 双雄的舞台 | 《尖峰时刻》(1998)：香港警察李警官与洛杉矶警察卡特搭档，语言不通、风格不合，破案靠配合 | 双雄戏的布景是“两个人的地盘” —— 警局、街头、赌场，谁的地盘谁说了算 | 场景：办公室布景 + 户外街道；机位：indoor-ots 双人对话；动作：walk / run |
| 1.6 | 钟楼 —— 高处即赌注 | 《A计划》(1983)：成龙吊在钟楼指针上，坠落三层楼，穿过两层布篷落地；为拍好这一跳他跳了三次，脊椎受伤仍继续演完 | 高处戏的赌注是高度本身 —— 观众要看清他离地面多远 | 场景：户外高处布景；走位：带高度的 waypoints；机位：crane-up。**注意：控制台无真实高空坠落，坠落只能用 wireFly / rappel + 反应镜头暗示，绝不能声称“真的跳了”** |

## 2. 拍摄 FILMING — 5 种模式

| # | 模式 | 例子 | 关键点 | 导演台可用的设置 |
|---|---|---|---|---|
| 2.1 | 宽景拍全套动作 —— 一镜看清，不切 | 《警察故事》(1985)、《A计划》(1983)：成龙的打斗多用宽景长镜头，观众能看清每一拳从哪来、落到哪去、撞到什么；镜头不切，真实才成立 | 动作戏默认宽景 —— 切得越碎，观众越不信；一镜到底是成龙的签名 | 机位：indoor-wide（室内）或 orbit 远景（室外）；规则：一个打斗节拍内不切特写 |
| 2.2 | 环境即武器 —— 每样东西都能打 | 《红番区》(1995)：超市货架、冰箱、购物车全是武器；《警察故事》(1985)：商场里的每块玻璃都被用上了；《醉拳》(1978)：酒坛、桌子、椅子都是醉拳的道具 | 布景不是背景，是武器库 —— 开打前先让观众看清房间里有什么 | 规则：开打前一个 wide 定场，展示所有可用道具；14 个程序化特技道具全数可用 |
| 2.3 | 痛感反应镜头 —— 疼要演出来 | 《警察故事》(1985)：滑杆时手被烫伤、落地时骨盆脱臼，成龙的表情全是真的疼；《A计划》(1983)：钟楼坠落后面不改色继续演，疼在脸上 | 疼是喜剧的一部分 —— 观众笑，是因为他真的疼；不疼的打斗不成立 | 机位：indoor-closeup 给受击者的脸；动作：fall → getUp，中间留一拍“疼” |
| 2.4 | 慢动作只给 payoff —— 绝不给铺垫 | 《警察故事》(1985)：商场大战的高潮一刻用慢动作强调冲击；《A计划》(1983)：钟楼坠落的瞬间 | 慢动作是奖品，不是常态 —— 全慢就全都不落地 | **控制台无慢动作/速度控制**：用“定格式”替代 —— 决胜一击后切 closeup 反应镜头 + SFX（撞击声），并在手册里写明这是替代方案 |
| 2.5 | 花絮感 —— 第二遍证明是真的 | 成龙影片片尾必放 NG 花絮与受伤镜头，观众看完才信“他真的跳了”；《A计划》(1983) 钟楼坠落拍了三次，成片用了两次不同的坠落 | 真实是成龙的品牌 —— 观众要看到“再来一次”，才信第一次 | 拍摄模拟预览当“排练”：先跑一遍模拟，再正式拍；同一特技拍两次不同版本，当花絮用 |

## 3. 动作 ACTION — 5 条原则

| # | 原则 | 例子 | 导演台可用的设置 |
|---|---|---|---|
| 3.1 | 道具三连 —— 一件道具，三种用法 | 《红番区》(1995)：超市里一把梯子先当盾、再当桥、最后当武器；《警察故事》(1985)：一把雨伞、一张椅子、一根灯杆轮流上场 | 动作预设：fight 3–8 拍，每拍换一件道具；道具必须在开场 wide 里出现过 |
| 3.2 | 借力打力 —— 用对手的力打对手 | 《醉拳》(1978)：醉拳的精髓是东倒西歪里借力；《A计划》(1983)：钟楼上借指针的摆动脱身 | 动作预设：dodge / block → punch / kick；先躲后打，躲的那拍必须看得见 |
| 3.3 | 逃跑即打斗 —— 追逐就是动作戏 | 《警察故事》(1985)：开场贫民窟追车、双层巴士追逐；《红番区》(1995)：气垫船追逐穿过纽约街头 | 动作预设：run / climb / leap / jump 编成追逐链；走位：多段 waypoints 穿过布景 |
| 3.4 | 醉拳 —— 乱即套路 | 《醉拳》(1978)：黄飞鸿装醉，东倒西歪，出拳却准；苏化子的训练是“醉着练、醒着打” | 动作预设：crouch / fall / getUp / turn 编成“醉步”；乱中有序 —— 每一次跌倒都要接一次出拳 |
| 3.5 | 大特技收尾 —— 一场戏一个真家伙 | 《A计划》(1983)：钟楼坠落；《警察故事》(1985)：滑杆撞碎玻璃；《红番区》(1995)：气垫船冲进街头 | 动作预设：wireFly / rappel / leap 当“特技收尾”，只用一次，放在全场最后一拍；**注意：控制台的 wireFly/rappel 是走位动作，不是真实坠落 —— 绝不能声称演员真的跳了，危险动作一律用道具 + 反应镜头代替** |

## 4. 镜头 CAMERA — 4 种模式

| # | 模式 | 例子 | 导演台可用的设置 |
|---|---|---|---|
| 4.1 | indoor-wide 默认 —— 全身动作一镜看清 | 《警察故事》(1985)、《A计划》(1983)：打斗默认宽景，同时看到表演者和他撞到什么、落在哪里 | 机位：indoor-wide；打斗戏默认 wide，跌倒中绝不切特写 |
| 4.2 | orbit 给 360° 环绕 —— 围着打斗转 | 《红番区》(1995)：超市大战、街头追逐，镜头绕着主角转，观众看清四面八方 | 机位：orbit；只给多人打斗与追逐，单人对话戏不用 |
| 4.3 | closeup 给痛感反应 —— 疼在脸上 | 《警察故事》(1985)：滑杆后烫伤的手、落地后扭曲的脸；《醉拳》(1978)：被打中后的龇牙咧嘴 | 机位：indoor-closeup；特写给受击者的脸，不是拳头 |
| 4.4 | crane-up 给高度 —— 升起来看他离地多远 | 《A计划》(1983)：钟楼坠落前，镜头先升起来看高度；《警察故事》(1985)：商场滑杆前，镜头先看清杆子有多高 | 机位：crane-up；特技之前先升起来立住高度，特技之后立刻切回地面 |

| # | 造型 | 例子 | 导演台可用的设置 |
|---|---|---|---|
| 5.1 | 功夫练功服 —— 醉拳的年代 | 《醉拳》(1978)：黄飞鸿的练功服、苏化子的破衣烂衫；衣服越旧，功夫越真 | 服装提示：练功服 + 时代锁（清末）；破旧即资历，越破越强 |

## 6. 不要抄这些 — 5 个失败模式

1. **假装危险是真的。**成龙的品牌是“真的跳了”，控制台的 wireFly/rappel 只是走位动作；模仿者声称“演员真的从钟楼跳下来”，等于造假。规则：特技一律用道具 + 反应镜头暗示，绝不在预设里写“真实坠落”。
2. **切碎打斗。**成龙的打斗一镜看清，剪辑越碎越不可信；模仿者用快切掩盖动作设计，观众立刻出戏。规则：一个打斗节拍内不切特写，wide 拍完再给反应镜头。
3. **英雄刀枪不入。**成龙每次打完都一身伤 —— 烫伤、脱臼、流血；模仿者让主角毫发无损地打赢，胜利就不值钱。规则：每场大打斗后必须有一拍“疼”（fall → getUp + closeup 反应），没有疼的胜利不进预设。
4. **抄枪，不抄拳。**成龙的动作喜剧里枪极少 —— 《警察故事》(1985) 开场他用手枪逼停巴士，但全片的核心是拳脚与道具；模仿者一开打就掏枪，等于放弃了成龙。规则：**控制台无开枪动作**，一律用 fight + SFX；枪只能当台词道具，不能当动作。
5. **道具只用一次。**成龙的道具三连是“一件道具，三种用法”；模仿者每件道具用一次就扔，布景就成了垃圾场。规则：每件道具至少用两次 —— 第一次当笑话，第二次当武器。

## 7. 预算 — 便宜 / 贵

**便宜（不用花钱 —— 这就是成龙的核心）：**
- 一个房间 + 一件道具：武馆里一张桌子、一把椅子就能打一场。成本：布景 + 走位。
- 痛感反应：一个特写、一张疼的脸，成本为零，效果最真。
- 追逐：一条街、几个人，跑起来就是动作戏。成本：走位。
- 服装即阵营：水师 vs 海盗、警察 vs 混混，服装一分，敌我自明。成本：服装。

**贵（需要大布景或众多群众演员 —— 在导演台里标出来）：**
- 商场大战：《警察故事》(1985) 的商场需要多层布景与大量糖玻璃。导演台提示：“控制台无商场中庭 —— 用市场 + 多层走位代替，别建商场。”
- 钟楼坠落：《A计划》(1983) 的钟楼是实景高空特技。导演台提示：“控制台无真实高空坠落 —— 用 wireFly + 反应镜头暗示，绝不声称真的跳了。”
- 气垫船追逐：《红番区》(1995) 的气垫船追逐需要水面与特技。导演台提示：“控制台无水体/CGI 载具模型 —— 追逐用街道 + run/climb 代替，别做船。”

**给导演台的底线：** 成龙动作是布景 + 道具 + 一次真疼，不是钱。预设默认便宜档（一间房、一件道具、一次疼的反应），把商场大战、钟楼坠落、气垫船追逐标为升级项 —— 并且永远标明“危险动作只做暗示，不做真实坠落”。
