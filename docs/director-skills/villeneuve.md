# 丹尼斯·维伦纽瓦 — 导演手册（Denis Villeneuve Playbook）

> 范围：丹尼斯·维伦纽瓦自魁北克法语片起步（《理工学院》*Polytechnique* 2009、《焦土之城》*Incendies* 2010），英语片以《囚徒》*Prisoners* (2013)、《边境杀手》*Sicario* (2015) 打开局面，本手册以 5 部锚定片为核心：科幻《降临》*Arrival* (2016)、《银翼杀手 2049》*Blade Runner 2049* (2017)、《沙丘》*Dune* (2021)、《沙丘 2》*Dune: Part Two* (2024)，惊悚《边境杀手》*Sicario* (2015)。
> 主类型：**科幻**。另注：边境惊悚（《边境杀手》）—— 维伦纽瓦的惊悚和科幻是同一套语言：寂静、尺度、等待。
> 核心 DNA：**寂静 + 尺度 + 渺小的人对巨大的世界** —— 人在画面里很小，建筑、沙漠、飞船很大；对白很少，声音设计很重；每个世界一种颜色；时间、记忆、身份是真正的剧情。
> 状态：已接入导演台风格预设（2026-11-16，`src/lib/directorStyles.ts`）。

## 什么时候用

- 科幻短剧、沙漠星球、外星接触、未来都市、末世废土。
- 边境、缉毒、卧底、审讯、两个世界之间的灰色地带也可用 —— 《边境杀手》就是没有外星人的《降临》。
- 想让一场戏“安静但压得人喘不过气”时用这套：一个人站在大空地上，什么都不说，就够。
- 预算中等时优先用这套 —— 维伦纽瓦的核心是尺度和克制，贵的是实景大场面，便宜的是“留白”。

## 1. 布景 SETS — 6 种场景类型

| # | 场景类型 | 例子 | 关键点 | 导演台可用的设置 |
|---|---|---|---|---|
| 1.1 | 沙漠星球 —— 厄拉科斯 | 《沙丘》(2021)、《沙丘 2》(2024)：厄拉科斯（Arrakis）—— 无边沙丘、沙虫经过的沙纹、弗雷曼人的洞穴、哈克南人的黑色方块建筑；保罗第一次骑沙虫，全程没有配乐，只有风和沙 | 沙漠是“活的” —— 沙丘会动、沙虫会来、风会改写地形；人在沙漠里不是主角，是过客 | 场景：户外沙漠 / 雪地（沙丘用沙漠，洞穴用室内）；灯光 day（白天沙漠）/ dusk（黄昏）；走位：walk / climb 沿沙脊，配 crane-up；注：导演台没有沙虫/动物模型，沙虫只能用沙纹走位 + 震动 SFX + 反应镜头暗示，绝不拍虫身 |
| 1.2 | 外星飞船 / 草原 —— 降临现场 | 《降临》(2016)：蒙大拿草原上悬停的黑色“贝壳”飞船，内部是雾蒙蒙的白色大厅，人类语言学家露易丝隔着玻璃与七肢桶（heptapod）交流，学写圆形文字 | 接触不是战斗，是上课 —— 布景是“教室”：白、空、安静，只有一块玻璃隔开两个世界；语言本身就是剧情 | 场景：户外草原/空地 + 室内白色大厅；灯光 overcast（草原雾）/ cold（舱内）；动作：stand / point / walk 缓慢接近玻璃；剧本：写“今天学会了第几个词” |
| 1.3 | 未来洛杉矶 / 橙色拉斯维加斯 | 《银翼杀手 2049》(2017)：K（Ryan Gosling 饰）在洛杉矶的灰、雪、海墙之间穿行，走进拉斯维加斯废墟，整座城市泡在核辐射的橙色雾里；华莱士（Wallace）总部是空旷的石室，水光在墙上流动 | 一个城市一种颜色 —— 洛杉矶是灰，拉斯维加斯是橙，华莱士总部是水光；颜色变了，人物内心就变了 | 场景：现代街道（灰）+ 户外沙漠（橙色雾）+ 室内大厅（水光）；灯光 cold（洛杉矶）/ dusk（橙色废墟，近似）/ dramatic（总部）；注：导演台没有色彩分级滤镜，单色世界只能靠灯光预设 + 服装同色近似，不能一键变橙 |
| 1.4 | 边境沙漠 / 隧道 —— 灰色地带 | 《边境杀手》(2015)：美墨边境 —— 车队从高空俯瞰进入华雷斯（Juárez），隧道里夜视镜下的突袭，沙漠里无声的处决；亚历杭德罗（Alejandro）全程几乎不说话 | 边境是“没有法律的地方” —— 布景越空、越热、越安静，暴力越可怕；最吓人的场面是车队在公路上慢慢开，什么都没发生 | 场景：户外沙漠/公路 + 室内隧道/仓库；灯光 day（沙漠）/ night（隧道夜视近似）；走位：车队 waypoints 直线，配 walk / crouch；注：导演台没有枪械/射击动作，隧道突袭只能用 fight + SFX（枪声）暗示，画面里不演开枪 |
| 1.5 | 巨型建筑 —— 权力的空房间 | 《银翼杀手 2049》(2017)：华莱士总部空旷石室；《沙丘 2》(2024)：哈克南母星杰迪主星（Giedi Prime）的竞技场，在黑太阳下拍成黑白世界 | 建筑即权力 —— 房间越大，人越小，权力越大；空房间比满房间更吓人 | 场景：室内大厅/宫殿（空旷、石质）；灯光 dramatic / cold；走位：一个人 walk 穿过空房间，配 indoor-wide；注：杰迪主星的黑白世界是红外摄影效果，导演台没有黑白/色彩分级滤镜，只能用 cold / moonlight 近似，须在预设里注明“无法还原黑白” |
| 1.6 | 室内审讯 / 实验室 —— 记忆与身份 | 《银翼杀手 2049》(2017)：K 接受“基线测试”（baseline test），被反复问同一个问题，回答稍有偏差就暴露；《降临》(2016)：露易丝在帐篷实验室里一次次看圆形文字，记忆开始错乱 | 审讯不是问话，是“测人” —— 房间越小、越白、越没有窗，人物越无处可躲；测试的问题本身就是剧情 | 场景：室内实验室/审讯室；灯光 cold；机位 ots + indoor-closeup；动作：sit / stand / idle，全程克制 |

## 2. 拍摄 FILMING — 5 种模式

| # | 模式 | 例子 | 关键点 | 导演台可用的设置 |
|---|---|---|---|---|
| 2.1 | 静默开场，声音后至 | 《降临》(2016)：开场没有爆炸，只有一艘船悬在草原上，人群远远看着；《沙丘》(2021)：沙虫来之前，先是寂静，再是沙面震动；《边境杀手》(2015)：车队进入华雷斯，全程几乎没有配乐 | 寂静是维伦纽瓦的配乐 —— 先让观众听见“没有声音”，再让声音进来，声音就有了重量 | 音乐库：开场不用音乐，只留环境 SFX（风声、脚步）；声音进来时只用一个低音或一声巨响 |
| 2.2 | 人小景大 —— 尺度即情感 | 《沙丘》(2021)：保罗站在沙丘上，沙漠占满画面，人只是一个点；《银翼杀手 2049》(2017)：K 站在巨大的雕像、垃圾场、橙色废墟前；《边境杀手》(2015)：车队从高空看只是几条线 | 人越小，世界越大，观众越能感到“这个人扛不住” —— 尺度不是炫耀，是同情 | 机位：crane-up / orbit 大远景，人物放在画面边缘或底部；走位：一个人 walk 穿过大场景，time 拉长 |
| 2.3 | 单色一世界 —— 颜色即内心 | 《银翼杀手 2049》(2017)：洛杉矶灰、拉斯维加斯橙、雪地白，每种颜色对应 K 内心的一个阶段；《沙丘 2》(2024)：杰迪主星黑白，哈克南世界没有颜色，因为没有人性 | 颜色不是美术，是心理 —— 换颜色就是换人物状态；一个场景只用一种主色，绝不杂 | 灯光：每场只选一个预设（cold / dusk / moonlight）；服装：全员同色系；注：无色彩分级滤镜，单色只能近似，须注明差距 |
| 2.4 | 非线性 / 记忆闪回 —— 时间是谜 | 《降临》(2016)：露易丝的“闪回”其实是“闪前”—— 她看见的女儿的未来，是她学会外星语言之后才拥有的时间感；《沙丘 2》(2024)：保罗的幻象反复出现，未来和现在互相渗透 | 时间不是直线，是“学会语言之后才看得见的东西” —— 闪回不是解释，是揭示：观众和主角同时才明白 | 分镜：把“现在”和“未来/记忆”写成两组分镜，靠服装/灯光区分（现在 cold，记忆 warm）；注：导演台没有多时间线模板，不能自动并行两条时间线，只能靠分镜顺序 + 剧本注释手动排，须在预设里注明 |
| 2.5 | 长镜头 + 少对白 —— 让画面自己讲 | 《沙丘 2》(2024)：保罗骑沙虫，全程几乎没有台词，只有风、沙、呼吸；《边境杀手》(2015)：亚历杭德罗在晚餐桌上杀人，全程没有解释 | 对白越少，画面越重 —— 一句台词能讲清的，就别讲两句；讲不清的，就别讲，让观众自己看 | 剧本：每场最多 3 句台词；拍摄模拟：preview 只检查走位和构图，不检查台词量；动作：walk / stand / idle，配长 hold |

## 3. 动作 ACTION — 5 条原则

| # | 原则 | 例子 | 导演台可用的设置 |
|---|---|---|---|
| 3.1 | 缓慢接近 —— 危险在前面，不在后面 | 《沙丘》(2021)：保罗一步步走向沙虫、走向沙漠深处；《降临》(2016)：露易丝一步步走向玻璃、走向七肢桶；《边境杀手》(2015)：车队一步步开进华雷斯 | 接近是“明知危险还要走过去” —— walk 要慢、要直、要停；每停一次，观众就紧张一次 | 动作：walk（慢）/ stand / idle，配 waypoints 直线 + 长 time；机位 dolly-in 跟在身后 |
| 3.2 | 边境车队 / 伏击 —— 秩序中的暴力 | 《边境杀手》(2015)：车队、隧道、夜视镜，暴力来得突然、短促、无声；《沙丘 2》(2024)：弗雷曼人伏击哈克南车队，沙地里突然冒出人 | 暴力不是高潮，是“秩序裂开一条缝” —— 之前越安静、越整齐，暴力越吓人；暴力之后立刻恢复安静 | 打斗编排：fight 3–8 beats，用 punch / kick / block / dodge / fall / getUp；注：无枪械动作，枪战用 fight + SFX 暗示；车队用 ride / walk waypoints |
| 3.3 | 决斗 / 仪式 —— 一对一，别无选择 | 《沙丘 2》(2024)：保罗在竞技场与菲德-罗萨（Feyd-Rautha）决斗，杰迪主星黑白世界里两个人、一把刀；《沙丘》(2021)：保罗与詹米斯（Jamis）的决斗，赢了才能活 | 决斗是“没有退路” —— 场地越小、越空，决斗越重；仪式（鞠躬、亮刀、等待）比打斗本身更重要 | 打斗编排：fight 3–8 beats，开场先 bow / stand 对峙 2 beats，再打；机位 indoor-wide（室内）/ orbit（户外） |
| 3.4 | 语言 / 沟通即动作 | 《降临》(2016)：露易丝学写圆形文字、第一次摘下防护服走进雾里、第一次“听懂”七肢桶 —— 每一次沟通都是一次冒险；《银翼杀手 2049》(2017)：K 的基线测试，回答本身就是动作 | 沟通不是“说话”，是“冒险” —— 摘下面罩、走近玻璃、写下第一个词，每一步都可能死；动作要拍“手”和“眼”，不拍嘴 | 动作：point / wave / stand / walk 缓慢接近；机位 indoor-closeup 给手和眼；剧本：写“今天学会了第几个词” |
| 3.5 | 逃亡 / 穿越 —— 穿过世界，不是打败世界 | 《银翼杀手 2049》(2017)：K 穿过海墙、穿过雪地，带着德卡德逃走；《沙丘》(2021)：保罗和杰西卡穿过沙漠，走向弗雷曼人 | 逃亡不是追逐，是“穿越” —— 穿过沙漠、穿过城市、穿过雪地，世界本身就是障碍；跑起来不如走过去有分量 | 走位：waypoints 长距离穿越，配 walk / run / climb；机位 crane-up 跟拍，人物在画面里越来越小 |

## 4. 镜头 CAMERA — 4 种模式

| # | 模式 | 例子 | 导演台可用的设置 |
|---|---|---|---|
| 4.1 | 大远景 / 摇臂显尺度 | 《沙丘》(2021)：沙漠、沙虫沙纹、香料采集器；《银翼杀手 2049》(2017)：洛杉矶、垃圾场、橙色拉斯维加斯；《边境杀手》(2015)：车队从高空进入华雷斯 | 远景是“世界有多大” —— 人在远景里只是一个点，点越小，世界越真；远景之后必须立刻切回人的脸 | 机位：crane-up / orbit（户外）；灯光 day / dusk |
| 4.2 | 缓慢推近 —— 只给揭示时刻 | 《降临》(2016)：镜头慢慢推向飞船、推向玻璃后的七肢桶；《沙丘 2》(2024)：镜头慢慢推向保罗的脸，他第一次“看见”未来 | 推近是“逼近真相” —— 一场戏只推一次，推到最关键的那个物体或那张脸上就停住 | 机位：dolly-in，配长走位时间；注：无速度控制，慢靠时间拉长实现 |
| 4.3 | 宽景、空房间拍孤独 | 《银翼杀手 2049》(2017)：华莱士总部空旷石室，K 一个人站在里面；《降临》(2016)：白色大厅里露易丝一个人面对玻璃 | 空房间是“孤独的形状” —— 房间越大，人越孤独；别用特写抢戏，让空房间自己说话 | 机位：indoor-wide；灯光 cold / dramatic；动作 stand / idle |
| 4.4 | 特写给克制的脸 —— 不给表情，只给眼神 | 《银翼杀手 2049》(2017)：K 的脸全程克制，特写只给眼神变化；《边境杀手》(2015)：亚历杭德罗的脸几乎没有表情，特写只给他在晚餐桌上的一次眨眼 | 特写是“克制裂开一条缝” —— 平时绝不用特写，只在人物内心翻转的那一秒用 | 机位：indoor-closeup；一场戏最多一个特写，放在动作之后 |

## 5. 装束 COSTUMES — 4 个造型

| # | 造型 | 例子 | 导演台可用的设置 |
|---|---|---|---|
| 5.1 | 蒸馏服 —— 沙漠里的第二层皮肤 | 《沙丘》(2021)、《沙丘 2》(2024)：弗雷曼人蒸馏服（stillsuit），黑色、贴身、回收每一滴水；保罗从贵族白衣换成蒸馏服，就是从“少爷”变成“沙漠人” | 蒸馏服即生存 —— 穿上它才能在沙漠活，脱下它就是死；服装即功能，不是装饰 | 服装预设：沙漠/功能服 archetype，深色、贴身；换装一次：贵族服 → 蒸馏服 |
| 5.2 | 未来极简灰 / 黑 —— 复制人与造物主 | 《银翼杀手 2049》(2017)：K 穿灰色长外套，华莱士穿白色长袍，乔伊（Joi）换装无数次 —— 衣服越简单，人越像“产品” | 极简即“被制造” —— 颜色越少、线条越干净，人越像被设计出来的；主角的衣服要比背景深一度，才能从灰里跳出来 | 服装预设：现代极简 archetype，灰/黑；华莱士白袍 archetype，全员同色系 |

## 6. 不要抄这些 — 5 个失败模式

1. **尺度没有人就成了风景片。**《沙丘》(2021) 的沙漠再大，核心还是保罗“要不要成为救世主”的选择。模仿者只拍大沙漠、大建筑、大远景，人物只剩一个点，观众记住风景、忘掉人。规则：每个大远景必须配一个人物问题（他要什么？他怕什么？），答不出就别拉远景。
2. **寂静成了无聊。**维伦纽瓦的寂静里面有信息（风、沙、呼吸、脚步），不是“没有声音”。模仿者把寂静当风格，镜头推半天什么都没发生、什么都没听见，观众只会走神。规则：每个静默镜头必须有一种声音（风、沙、呼吸、机器低鸣），没有声音设计就别静默。
3. **抄单色，不抄心理。**拉斯维加斯的橙、杰迪主星的黑白，在维伦纽瓦手里是人物内心的颜色，在模仿者手里只是“好看的滤镜”。规则：换颜色之前先写一句“这个颜色 = 人物此刻的什么心情”，写不出就别换灯光。
4. **非线性成了炫技。**《降临》(2016) 的时间结构成立，是因为它就是剧情（学会语言 = 看见时间）。模仿者把时间线打碎、闪回乱插，观众只会糊涂。规则：没有“时间本身就是剧情”的理由，就别用非线性；导演台也没有多时间线模板，别硬做。
5. **克制成了面瘫。**K、亚历杭德罗、保罗全程克制，但克制里面有裂缝：K 的一次眨眼、亚历杭德罗晚餐桌上的一次停顿、保罗第一次骑沙虫时的呼吸。模仿者只抄面无表情，忘了克制要有一条裂缝。规则：每场戏至少一个“裂缝”瞬间 —— 一次眨眼、一次停顿、一次呼吸加重，特写只给那一秒。

## 7. 预算 — 便宜 / 贵

**便宜（不用花钱 —— 这就是维伦纽瓦的核心）：**
- 留白是最便宜的美术：一个空房间、一个人、一盏灯，孤独就有了。成本：布景，不用群众演员。
- 寂静 + 环境音：风声、脚步、呼吸 SFX，盖过配乐。成本：音效，不是作曲。
- 人小景大：crane-up 大远景，人物放在画面边缘。成本：走位，不是搭建。
- 单色一世界：一个灯光预设 + 全员同色服装。成本：灯光和服装。
- 少对白：每场最多 3 句台词，剧本写得少，排得快。成本：写作时间。

**贵（需要大布景或特效 —— 在导演台里标出来）：**
- 沙漠实景 / 沙虫：《沙丘》(2021) 的沙漠是实景拍摄，沙虫是 CGI，导演台没有沙虫/动物模型。导演台提示：“沙虫 —— 用沙纹走位 + 震动 SFX + 反应镜头暗示，别做 CGI 虫身。”
- 橙色拉斯维加斯 / 黑白杰迪主星：《银翼杀手 2049》(2017) 的橙色雾和《沙丘 2》(2024) 的红外黑白是摄影 + 后期，导演台没有色彩分级/黑白滤镜。导演台提示：“单色世界 —— 用灯光预设近似，别指望一键变色。”
- 巨型建筑 / 飞船：《降临》(2016) 的贝壳飞船、《银翼杀手 2049》(2017) 的华莱士总部是实景 + 特效。导演台提示：“巨型建筑 —— 用室内大厅 + indoor-wide 暗示，别建真飞船。”
- 边境车队 / 大场面：《边境杀手》(2015) 的车队和华雷斯全景需要多车、多人、实景。导演台提示：“车队 —— 用 2–3 人 waypoints 小队 + SFX 暗示，别做大车队；导演台没有 crowd-sync。”

**给导演台的底线：** 维伦纽瓦是寂静 + 尺度 + 克制，不是钱。预设默认便宜档（一个空房间、一个人、一种颜色、一段风声），把沙虫 CGI / 黑白滤镜 / 巨型建筑标为升级项，不是必需项。
