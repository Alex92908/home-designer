# 雷德利·斯科特 — 导演手册（Ridley Scott Playbook）

> 范围：雷德利·斯科特自《决斗者》*The Duellists* (1977) 起导演 20+ 部长片，本手册以 5 部锚定片为核心：科幻《异形》*Alien* (1979)、《银翼杀手》*Blade Runner* (1982)、《火星救援》*The Martian* (2015)，公路《末路狂花》*Thelma & Louise* (1991)，历史史诗《角斗士》*Gladiator* (2000)。
> 主类型：**科幻**。另注：历史史诗（《角斗士》）、公路/女性复仇（《末路狂花》）—— 斯科特是“世界构建型”导演，换类型先换世界，再换人。
> 核心 DNA：**世界先行 + 烟雾雨霓虹 + 蓝领科幻 + 公司即反派** —— 先让观众相信这个世界真实存在（铆钉、烟、雨、灰、旧设备），再把一个普通人扔进去；史诗尺度配亲密人物，结尾总有一个人站着。
> 状态：已接入导演台风格预设（2026-11-16，`src/lib/directorStyles.ts`）。

## 什么时候用

- 科幻短剧、太空飞船、赛博都市、火星/异星生存、末世废土。
- 历史史诗、竞技场、公路逃亡、两个人的出走戏也可用 —— 《角斗士》和《末路狂花》是同一套“世界 + 幸存者”语言。
- 想让一场戏“看起来像真地方”时用这套：烟、雨、旧设备、做旧的墙，比任何台词都管用。
- 预算中等时优先用这套 —— 斯科特的核心是美术和氛围，贵的是大场面，便宜的是“旧”。

## 1. 布景 SETS — 6 种场景类型

| # | 场景类型 | 例子 | 关键点 | 导演台可用的设置 |
|---|---|---|---|---|
| 1.1 | 飞船货舱 —— 太空里的卡车 | 《异形》(1979)：商业拖船诺斯特罗莫号（Nostromo）—— 狭窄走廊、铆钉舱壁、闪烁的荧光灯、餐厅、冬眠舱；船员是领工资的蓝领，吃坏饭、吵奖金，只想回家 | 太空不是探险，是上班 —— 布景要“住过、用过、修过”：旧、脏、挤、到处是管道；怪物出现之前，观众先要相信这是一艘真船 | 场景：室内飞船舱（用现代室内/办公室布景改 dress，窄走廊 + 低矮天花板）；灯光 cold / dramatic；走位：沿走廊直线 hide / crouch 搜寻 |
| 1.2 | 赛博都市雨夜 —— 2019 年的洛杉矶 | 《银翼杀手》(1982)：雨、霓虹、广告牌、飞行车、拥挤的街市；德卡德（Deckard）在雨里追捕复制人，罗伊（Roy Batty）在楼顶雨中说出“雨中之泪” | 城市是主角 —— 雨和霓虹不是背景，是情绪；楼越高，人越小；广告越亮，街道越暗 | 场景：现代街道 + 室内酒吧/公寓；灯光 neon（街道）/ night（室内）；走位：雨夜 walk，配 indoor-wide → indoor-closeup |
| 1.3 | 火星栖息地 —— 一个人的实验室 | 《火星救援》(2015)：马克·沃特尼（Mark Watney）独自留在火星 —— 栖息舱、土豆田、漫游车、NASA 休斯顿控制室；他靠科学和幽默一段段解决“怎么活下去” | 生存是劳动 —— 布景是工具间，不是风景：种土豆、修设备、算轨道，每一步都看得见、摸得着 | 场景：室内实验室/栖息舱 + 户外沙漠（火星）；灯光 day（沙漠）/ cold（舱内）；动作：walk / climb / crouch 修理，配 script 里的“科学日志”式台词 |
| 1.4 | 罗马竞技场 —— 帝国的心脏 | 《角斗士》(2000)：开场日耳曼森林战役，罗马斗兽场里马克西姆斯（Maximus）从奴隶角斗士打成全民英雄；麦田幻象反复出现，是他回家的路 | 竞技场是“世界缩小成一个圆” —— 观众席即全世界，沙地即审判场；麦田是反义词：安静、私人、没有观众 | 场景：户外竞技场（用户外空地/广场布景）+ 户外麦田/农场；灯光 dusk（竞技场黄昏）/ day（麦田）；打斗：fight 3–8 beats（见 3.3） |
| 1.5 | 沙漠公路 / 峡谷 —— 两个人的出走 | 《末路狂花》(1991)：塞尔玛与路易丝开车出走 —— 加油站、汽车旅馆、沙漠公路，最后停在大峡谷边缘，车冲向空中，画面定格 | 公路是“越走越没有回头路” —— 布景越空，人物越自由，也越危险；结尾不用拍坠落，定格就是结局 | 场景：户外公路/沙漠 + 室内汽车旅馆；灯光 dusk（黄昏公路）；走位：ride（开车）→ stand 在峡谷边；注：导演台没有车辆坠落特效，结尾用 crane-up + 定格分镜处理 |
| 1.6 | 公司总部 / 实验室 —— 看不见的反派 | 《异形》(1979)：维兰德-汤谷公司（Weyland-Yutani）只以命令和机器人艾什（Ash）的形式出现；《银翼杀手》(1982)：泰瑞尔（Tyrell）金字塔顶层，复制人的“造物主”住在云端 | 反派不是怪物，是公司 —— 总部越高、越干净、越空，越可怕；怪物只是公司派来的“产品” | 场景：室内办公室/实验室（高层、空旷）；灯光 cold；走位：ots 过肩对峙（见 4.3） |

## 2. 拍摄 FILMING — 5 种模式

| # | 模式 | 例子 | 关键点 | 导演台可用的设置 |
|---|---|---|---|---|
| 2.1 | 先建世界，再进人物 | 《异形》(1979)：开场先拍空船 —— 走廊、餐厅、冬眠舱，一个人都没有，观众先记住船，再认识船员；《银翼杀手》(1982)：开场先拍 2019 年洛杉矶全景 + 火焰，再进德卡德 | 世界立住了，人物才有地方可站 —— 定场镜头不是“交代”，是“说服” | 开场：crane-up / orbit 大远景定场，再接 indoor-wide 进室内；灯光先定（neon / cold），再进人 |
| 2.2 | 氛围即叙事 —— 烟、雨、尘、雾 | 《异形》(1979)：走廊里永远有烟和雾，异形藏在阴影里；《银翼杀手》(1982)：雨从头下到尾；《火星救援》(2015)：火星沙尘暴开场；《角斗士》(2000)：战场烟尘 | 氛围不是装饰，是信息 —— 烟 = 看不见敌人，雨 = 无处可躲，尘 = 世界在崩坏；换氛围就是换剧情 | 灯光：neon（雨夜）/ cold（飞船）/ overcast（沙尘）/ dusk（战场）；SFX：雨声、风声、机器低鸣，盖过台词 |
| 2.3 | 实用主义科幻 —— 旧的才是真的 | 《异形》(1979)：诺斯特罗莫号到处是铆钉、油污、坏掉的灯；《银翼杀手》(1982)：飞行车、雨衣、街边小吃摊，全是旧的、修过的；《火星救援》(2015)：沃特尼用胶带和土豆活下去 | 未来不是新的，是“用旧了的未来” —— 新东西不可信，旧东西才可信；道具越破，世界越真 | 布景：复用现代室内/街道，dress 成旧的（灯光 cold + 做旧服装）；道具：程序化道具里选“旧设备、工具、管道” |
| 2.4 | 高潮反转权力 —— 幸存者站起来 | 《异形》(1979)：雷普利（Ripley）从船员变成最后一人，穿上宇航服、把异形弹出气闸；《角斗士》(2000)：马克西姆斯在竞技场里从奴隶变成“角斗士”，全场为他欢呼；《末路狂花》(1991)：两个女人在峡谷边选择不回头 | 权力反转要“看得见” —— 从 crouch / hide 到 stand，从被追到追人，动作和机位一起变 | 动作：hide / crouch → stand / walk → fight；机位：indoor-medium → indoor-wide，人物从画面边缘走到中央 |
| 2.5 | 蒙太奇解决问题 —— 科学即剧情 | 《火星救援》(2015)：沃特尼种土豆、制水、改装漫游车、算回家的轨道，一段段“问题 → 试验 → 解决”；《角斗士》(2000)：马克西姆斯一场场角斗，一场比一场难 | 解决问题的过程就是戏 —— 每一步都要拍出来，不能跳过；观众跟着主角一起“算出来”，才信他能活 | 分镜：把“问题 → 试验 → 解决”写成 3–5 条连续分镜；注：导演台没有剪辑/转场特效，蒙太奇只能靠分镜顺序 + 剧本里的日期/日志台词衔接 |

## 3. 动作 ACTION — 5 条原则

| # | 原则 | 例子 | 导演台可用的设置 |
|---|---|---|---|
| 3.1 | 潜伏 / 搜寻 —— 怪物在暗处 | 《异形》(1979)：船员拿着探测器在走廊里一间间搜，异形在通风管里、在天花板上；雷普利最后独自搜船，动作越轻，越可怕 | 搜寻不是走路，是“每一步都可能出事” —— 慢、轻、停、听；怪物不出现比出现更吓人 | 动作：walk（慢）/ crouch / hide / prone，配 indoor-wide；SFX：探测器滴答声 + 呼吸声 |
| 3.2 | 追逐 / 逃亡 —— 城市即迷宫 | 《银翼杀手》(1982)：德卡德在雨夜街市追复制人，罗伊在楼顶追德卡德；《末路狂花》(1991)：两个女人开车逃亡，警察在后面追 | 追逐要“有地理” —— 先立住街道/楼顶的布局，再跑；跑错一条巷子，就是剧情 | 走位：waypoints 沿街道/楼顶，配 run / leap；机位 orbit 跟拍（户外） |
| 3.3 | 竞技场格斗 —— 一场比一场难 | 《角斗士》(2000)：马克西姆斯先打单人，再打多人，再打战车，最后打皇帝康茂德（Commodus）本人；每场都有新武器、新地形、新规则 | 格斗是“升级” —— 3–8 beats 一场，beat 之间加一个反应镜头（观众、对手、自己）；赢的方式每次都不一样 | 打斗编排：fight 3–8 beats，用 punch / kick / block / dodge / fall / getUp；道具：程序化道具里的剑/盾类（如有）或徒手；注：无枪械动作，冷兵器格斗用 fight beats 演 |
| 3.4 | 生存劳动 —— 干活就是动作 | 《火星救援》(2015)：沃特尼种土豆、修栖息舱、开车去找探路者号；《异形》(1979)：船员修船、搬货、检查设备 | 干活要拍“手” —— 种、修、搬、算，动作越具体，观众越信这个人能活下去 | 动作：crouch / climb / walk / stand，配室内实验室/户外沙漠；剧本：写“今天做了什么、还剩多少天”式日志 |
| 3.5 | 最后一人站立 —— 幸存者独白 | 《异形》(1979)：雷普利在逃生舱里录日志，“这是诺斯特罗莫号最后的幸存者”；《银翼杀手》(1982)：罗伊雨中独白后死去，德卡德抱着他 | 结尾不是胜利，是“活下来了” —— 动作减到最少（stand / sit / idle），台词只留一句，灯光只留一盏 | 动作：stand / sit / idle；机位 indoor-closeup；灯光 dramatic；音乐库选低沉曲目 |

## 4. 镜头 CAMERA — 4 种模式

| # | 模式 | 例子 | 导演台可用的设置 |
|---|---|---|---|
| 4.1 | 大远景 / 摇臂卖尺度 | 《银翼杀手》(1982)：洛杉矶全景、泰瑞尔金字塔；《角斗士》(2000)：罗马斗兽场全景、开场森林战役；《火星救援》(2015)：火星荒原，漫游车只是一个点 | 尺度是“世界有多大、人有多小” —— 远景里人越小，世界越真；远景之后必须立刻切回人 | 机位：crane-up / orbit（户外）；灯光 dusk / day |
| 4.2 | 宽景、烟雾、深焦拍搜寻 | 《异形》(1979)：走廊宽景，烟雾里人影若隐若现；《银翼杀手》(1982)：雨夜街市宽景，霓虹在雨里晕开 | 宽景里要“有东西可藏” —— 烟、雨、阴影、管道，怪物和人都藏在里面；观众要和主角一起找 | 机位：indoor-wide；灯光 cold / neon；SFX：环境音盖过台词 |
| 4.3 | 过肩对峙 —— 审问与谈判 | 《银翼杀手》(1982)：德卡德对复制人做 Voight-Kampff 共情测试，镜头在两人肩后切换；《角斗士》(2000)：马克西姆斯与康茂德在竞技场边对峙 | 过肩是“谁在看谁” —— 谁的肩在前，谁就是被审问的那个；别用特写抢戏 | 机位：ots；一场对峙只用 ots + indoor-medium，不切 closeup |
| 4.4 | 特写给汗、眼、手 —— 不给全脸 | 《银翼杀手》(1982)：罗伊雨中独白，雨水顺着脸流，特写只给眼和嘴；《异形》(1979)：雷普利的手在抖，汗顺着额头流 | 特写是“身体在说实话” —— 人嘴上说没事，手和眼已经出卖了他 | 机位：indoor-closeup；一场戏最多一个特写，放在动作之后 |

## 5. 装束 COSTUMES — 4 个造型

|---|---|---|---|

## 6. 不要抄这些 — 5 个失败模式

1. **世界构建吞掉故事。**《银翼杀手》(1982) 的洛杉矶再美，核心还是德卡德和罗伊“谁是人”的问题。模仿者花全部篇幅拍雨、霓虹、飞行车，人物只剩摆设，观众记住世界、忘掉人。规则：每个布景必须配一个人物问题（他要什么？他怕什么？），答不出就别建那个布景。
2. **雨和霓虹当壁纸。**雨、烟、霓虹在斯科特手里是信息（看不见、躲不开、被监视），在模仿者手里只是“看起来很赛博”。规则：每场雨/烟必须有功能 —— 藏人、挡路、暴露、隔绝，缺功能就关掉灯光特效。
3. **把公司拍成卡通反派。**维兰德-汤谷和泰瑞尔公司可怕，是因为他们“正常”—— 开会、发命令、讲利润，怪物只是副产品。模仿者把公司老板拍成狂笑的疯子，反而不可信。规则：公司反派要冷静、体面、讲道理，坏事由“程序”和“命令”来做，不由坏人来做。
4. **史诗没有亲密时刻。**《角斗士》(2000) 再大，核心是马克西姆斯摸麦穗、想回家；《异形》(1979) 再吓人，核心是雷普利护着猫琼斯（Jones）。模仿者只拍大战场、大竞技场，忘了给英雄一个安静的瞬间。规则：每场大戏之后必须有一个小戏 —— 一只手、一只猫、一片麦田，特写只给那一秒。
5. **幸存者没有代价。**雷普利活下来失去了全船人，马克西姆斯赢了角斗却死了，塞尔玛与路易丝自由了却没有回头路。模仿者让主角毫发无损地赢，胜利就显得很便宜。规则：幸存者结尾必须“少了点什么”—— 少一个人、少一条路、少一个家，写进剧本最后一句。

## 7. 预算 — 便宜 / 贵

**便宜（不用花钱 —— 这就是斯科特的核心）：**
- “旧”是最便宜的美术：复用现代室内/街道，灯光 cold + 做旧服装，世界就“住过”了。成本：灯光和服装，不是搭建。
- 烟、雨、雾即氛围：neon / cold 灯光 + 雨声/风声 SFX。成本：灯光和音效，不是特效。
- 一个走廊、一个房间：诺斯特罗莫号的恐怖只需要一条走廊 + hide / crouch。成本：走位。
- 科学日志式台词：《火星救援》(2015) 的生存戏靠剧本里的“今天做了什么”，不是靠布景。成本：写作时间。
- 换装即地位：将军 → 奴隶 → 角斗士，三套服装讲完命运。成本：服装。

**贵（需要大布景或众多群众演员 —— 在导演台里标出来）：**
- 赛博都市全景 / 飞行车：《银翼杀手》(1982) 的洛杉矶是模型 + 实景 + 特效，导演台没有飞行车/CGI 模型。导演台提示：“赛博都市 —— 用现代街道 + neon 灯光 + crane-up 暗示，别建飞行车。”
- 罗马斗兽场 / 大军团：《角斗士》(2000) 的斗兽场和开场战役需要大布景和群众演员。导演台提示：“竞技场 —— 用户外空地 + 5–8 人小队，别建万人场；群众演员用走位 + SFX 暗示，导演台没有 crowd-sync。”
- 异形 / 怪物模型：《异形》(1979) 的异形是 H.R. 吉格尔（H.R. Giger）设计的实体模型，导演台没有怪物/动物模型。导演台提示：“怪物 —— 永远不拍全貌，只拍阴影、爪痕、反应镜头（indoor-closeup 给脸）。”
- 火星荒原 / 沙尘暴：《火星救援》(2015) 的火星是实景 + 特效。导演台提示：“火星 —— 用沙漠布景 + overcast 灯光 + 沙尘 SFX，别做 CGI 沙尘暴。”

**给导演台的底线：** 斯科特是世界 + 氛围 + 一个幸存者，不是钱。预设默认便宜档（一条旧走廊、一场雨、一件工装、一个科学日志），把赛博全景/斗兽场/怪物模型标为升级项，不是必需项。
