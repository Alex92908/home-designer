### Sketchfab 下载步骤（一次设置）

1. 注册免费账号 <https://sketchfab.com/signup>
2. 登录后访问 <https://sketchfab.com/settings/password>，生成 API Token
3. 放入环境变量：`echo "SKETCHFAB_TOKEN=xxx" >> .env.local`
4. 运行 `node scripts/download-sketchfab.mjs` 批量下载已登记的 uid
