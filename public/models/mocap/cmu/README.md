# CMU mocap BVH clips

Six clips from the CMU Graphics Lab Motion Capture Database
(http://mocap.cs.cmu.edu/), BVH conversion by Bruce Hahne (cgspeed),
via the mirror https://github.com/una-dinosauria/cmu-mocap.

| file | subject / motion | description (CMU index) | duration |
| --- | --- | --- | --- |
| cmu_walk.bvh | 02 / 02_01 | walk | 2.86 s |
| cmu_run.bvh | 09 / 09_01 | run | 1.23 s |
| cmu_idle.bvh | 140 / 140_06 | Idle | 29.68 s |
| cmu_sit.bvh | 13 / 13_01 | sit on high stool, stand up | 19.27 s |
| cmu_wave.bvh | 111 / 111_37 | Wave | 2.70 s |
| cmu_punch.bvh | 02 / 02_05 | punch/strike | 15.45 s |

All parse with three-stdlib `BVHLoader` (38 bones, 62 tracks, 120 fps).
