# 室内/场景设计评审 rubric + 参考库

> 目的：把「理性」和「艺术气息」拆成**可检查的规则**，让搭场景不靠临场发挥。
> 每搭完一个空间，逐条过 §1 的评审表；搭之前查 §3 对应场景的参考卡。
> 这份文件回答用户的问题——「怎样才能既理性又有艺术感」：靠**规则 + 参考 + 看图闭环**，
> 不靠灵感。

---

## 0. 核心工作循环（必须走完，别跳）

```
调研参考(§3 参考卡 / WebSearch 真实案例)
  → 列缺口(对照 furniture.ts 目录)
  → 摆(写坐标)
  → 渲染看图(§2 看图协议，真的开浏览器/预览看)
  → 逐条评审(§1 rubric 打分)
  → 挑最差的 2-3 条改
  → 再看再评，直到 rubric 无红项
```

「摆完就宣布完成」是搭积木；「看→挑毛病→改」才是设计。**看图闭环不可省。**

## 1. 评审 rubric（搭完逐条打勾，任一条不过就是红项要改）

### A. 焦点（Focal point）
- [ ] 这个空间有**一个明确视觉主角**吗？(壁炉 / 主背景墙 / 大吊灯 / 吧台 / 主沙发组)
- [ ] 进门第一眼落在主角上，还是一片平均、无处落眼？
- [ ] 其余家具是**服务/衬托**主角，还是各自抢戏？
> 反例：均匀撒家具，没有主次 = 最常见的新手病。

### B. 动线与分区（Circulation & Zoning）
- [ ] 主通道净宽 **≥ 90cm**（单人）/ **≥ 120cm**（对向过人 / 公共空间主道）？
- [ ] 没有家具堵门、堵窗、堵通道，人不用绕 S 形？
- [ ] 一个大空间被**划成清晰功能区**（就座区/通行区/服务区），不是一锅乱炖？
- [ ] 分区手段用上了没：地毯定义区、吊灯压区、矮柜/沙发背作软隔断？

### C. 尺度与比例（Scale & Proportion）— 数字是硬约束
- [ ] 每件家具的 `width/depth/height` 是**真实 cm**，不是拍脑袋？(比例失常 = 这里错)
- [ ] 家具彼此**间距**对：茶几离沙发 30–45cm；餐椅中心间距 ~60cm；床两侧留 ≥60cm 过道。
- [ ] 家具与**空间**比例对：小房间别塞巨物；大空间别摆一堆矮小件显得空。
- [ ] 高度错落有**层次**：不是一水儿齐腰高，有高柜/吊灯/立灯/矮几拉开天际线。
> 见 §4 常用真实尺寸速查。

### D. 留白（Negative space）
- [ ] 敢空吗？地面**可见空地 ≥ 30–40%**，不是塞满？
- [ ] 每件家具都有「呼吸感」，不贴着挤成一坨？
> 高级感一半来自克制。新手都塞太满。

### E. 光的层次（Lighting layers）
- [ ] 有**三层光**吗：主照明(顶灯/吊灯) + 氛围(壁灯/灯带/落地灯) + 重点(射灯打主角/画)？
- [ ] 不是一盏顶灯打平全场？
- [ ] 灯具本身也是装饰(造型吊灯/网红落地灯)，不只是功能？

### F. 色彩（Color 60-30-10）
- [ ] 主色 ~60%(大面：墙/地/大家具) + 辅色 ~30%(沙发/窗帘/柜) + 点缀 ~10%(抱枕/画/花/灯)？
- [ ] 有**一个统一基调**(暖木/冷灰/黑白/莫兰迪)，不是每件家具各一个色系？
- [ ] 有**至少一处点缀色**打破沉闷(一束花/一幅画/一个亮抱枕)？

### G. 细节与生活感（Styling / lived-in）
- [ ] 桌面/柜面有**小道具**吗(书、杯、花瓶、绿植、托盘)，还是光秃秃？
- [ ] 墙面不空：画 / 挂饰 / 书架 / 镜？
- [ ] 有绿植软化硬线条？
- [ ] 场景像「有人在用」，还是像展厅空壳？
> 生活感细节是「艺术气息」最廉价有效的来源。

## 2. 看图协议（怎么真的「看到」自己搭的东西）

**优先用 preview MCP，不要臆想。** 顺序：
1. `preview_start`（launch.json 里 `home-designer`，port 3000）。
2. 让场景进 store：dev 下 `preview_eval` 调 `window.__store.getState().applyProjectTemplate('set-cafe')`
   （或直接 setState 灌 floorPlans）。
3. 切到最能诊断布局的视图：
   - **`viewMode:"all"`** = 2D 俯视平面图 → **看动线/分区/间距/留白最准**（no 相机角度骗你）。
   - `viewMode:"3d"` 效果图 = 看单房间立体观感/光/配色。
   - `viewMode:"global3d"` 全屋 3D / `"exterior"` 外观。
4. `preview_screenshot` 出图**肉眼过 §1 rubric**；`preview_inspect` 核 CSS 数值。
5. 挑红项 → 改坐标/尺寸/加件 → 回 3 再看。

> ⚠️ 3D 相机角度会骗人：曾经「西挤东空」其实是镜头透视，切 `"all"` 2D 平面一看是均匀的。
> **判断布局用 2D `"all"`，判断观感/光/色用 3D。两个都要看。**
> preview harness 偶把视口压成 ~516px 竖条时，宽内景截不全 → 用 `window.__store` 数据层
> 核坐标兜底，或让用户在真浏览器看。

## 3. 场景参考库（搭之前查对应卡；数字是「典型真实值」，非死规定）

### ☕ 咖啡馆
- **焦点**：点单柜台 + 后吧台墙（背光/招牌/挂杯/咖啡机）。进门第一眼给柜台。
- **分区**：①点单区(柜台+展示柜沿一面长墙一字排开) ②窗边高脚位(南向玻璃,吧台桌+吧凳,中间留门)
  ③堂食密集桌位(2 人小圆桌为主,中部+靠墙) ④书架/装饰墙 ⑤后场备货(操作台+货架,当 kitchen)
  ⑥小 WC(坐便+立柱盆+镜,别塞住宅整套)。
- **必备清单**：点单柜台、甜品展示柜、咖啡机/磨豆机、后吧货架(罐/杯)、小圆桌×多、
  配套椅(每桌 2)、窗边吧台+吧凳、书架墙、成排吊灯(压柜台/桌上方)、门口 A 字黑板/欢迎牌、
  桌面小道具(咖啡杯/小花瓶)、绿植。
- **典型尺寸**：柜台高 105–110cm；吧凳座高 75cm；2 人小圆桌 Ø60–70cm；餐椅座高 45cm；
  桌间过道 ≥90cm；吊灯离桌面 70–80cm。
- **光**：暖白 3000K；成排小吊灯 + 后吧墙洗墙灯 + 窗自然光。
- **配色**：暖木 + 黑铁 + 奶白墙 + 绿植点缀。
- **常见错误**：柜台+设备全堆一角挤成一坨其余空；桌位均匀撒无疏密；无窗边高脚位；墙空。

### 🛋 客厅
- **焦点**：主沙发 + 电视墙/背景墙(或壁炉)。沙发朝焦点摆。
- **分区**：会客区(沙发+茶几+单椅 U/L 形围合) + 视听墙 + 可选阅读角(单椅+落地灯+边几)。
- **必备**：三人沙发、单人椅×1-2、茶几、电视柜+电视/背景墙、地毯(压住整个沙发组)、
  落地灯、边几、墙面装饰画(通常成组/一大幅)、绿植、抱枕(点缀色)、可选吊灯。
- **典型尺寸**：沙发深 90cm；茶几离沙发 30–45cm；茶几高 ≈ 沙发座高(40cm)；
  电视墙离沙发 2.5–3m；地毯要能压住沙发+茶几(前腿上毯)。
- **光**：主吊灯 + 落地灯氛围 + 画/柜射灯。**忌只一盏顶灯**。
- **配色**：大面中性(灰/米/木) 60% + 沙发主色 30% + 抱枕/画/花 10% 亮点缀。
- **常见错误**：沙发贴墙一圈四散不围合；地毯太小飘着；茶几太远；墙空一片;只顶灯。

### 🍜 餐厅 / 小餐馆
- **焦点**：主餐桌组(住宅) / 吧台或开放厨房(餐馆)。
- **分区**：就餐区(桌椅) + 备餐/中岛 + 可选卡座沿墙。
- **必备**：餐桌×N、餐椅(每桌配齐)、吊灯(正压餐桌中心)、餐边柜/备餐台、
  桌面道具(餐具/花/菜单立牌)、卡座(餐馆)、绿植/装饰墙。
- **典型尺寸**：4 人桌 120×80cm / 6 人 160×90cm；餐椅中心间距 60cm；
  桌离墙/后拉椅 ≥75cm，能过人 ≥90-100cm；吊灯离桌面 70-80cm。
- **光**：餐桌正上暖光吊灯(聚焦) + 环境补光。
- **常见错误**：吊灯没对准桌中心；桌椅太挤拉不开椅；一排桌无变化像食堂。

### 💼 办公室
- **焦点**：开放工位阵列 / logo 背景墙 / 会议玻璃房。
- **分区**：开放工位区 + 会议室(玻璃隔断) + 茶水/休息区 + 前台(可选)。
- **必备**：成排办公桌+办公椅、显示器道具、会议桌+椅、玻璃隔断、茶水台+高凳、
  绿植、白板、地毯分区、条形吊灯/格栅灯。
- **典型尺寸**：办公桌 120-140×60-70cm；工位过道 ≥90cm；会议桌每人 60cm 宽。
- **光**：均匀格栅/条形灯(功能) + 休息区暖光氛围。
- **常见错误**：工位方向乱；会议室没玻璃感；全冷光无休息区暖调对比。

### 🛏 卧室
- **焦点**：床 + 床头背景墙。
- **分区**：睡眠区(床+床头柜×2) + 可选梳妆/阅读角 + 衣柜。
- **必备**：双人床、床头柜×2、床头灯×2(对称)、床头背景墙(软包/画/挂饰)、
  地毯(床前/床两侧)、衣柜、可选梳妆台+凳 或 单椅阅读角、绿植/落地灯。
- **典型尺寸**：双人床 150-180×200cm；床两侧过道 ≥60cm；床头柜宽 40-50cm；
  床离衣柜(开门)≥70cm。
- **光**：吊灯/吸顶(主) + 对称床头灯(氛围/阅读)。暖光为主。
- **常见错误**：床贴侧墙没留过道；床头柜/灯不对称；墙空;只顶灯太亮无氛围。

## 5. 一句话心法

**理性** = 上面每条都是可查的数字和规则，不猜。
**艺术气息** = 焦点(A) + 留白(D) + 层次光(E) + 点缀色(F) + 生活感道具(G) 五者叠加的结果，
不是玄学。
**做到** = 每次都走 §0 循环，尤其**不跳看图闭环(§2)**。
